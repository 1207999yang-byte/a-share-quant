# A股量化工具 V2.0

## 功能
- 多因子选股：估值25%、盈利质量25%、成长20%、动量20%、低波10%
- 可调持仓数量、交易费率、现金比例
- 历史净值/收益率/年化收益/最大回撤/夏普
- 10万元仓位模拟
- CSV导入与结果导出

## 启动
Python 3.10+
pip install -r requirements.txt
streamlit run app.py

## 回测CSV
日期,收盘价
2020-01-02,100
2020-01-03,101

注意：V2.0的“历史回测”目前是对上传的策略/指数价格序列做净值回测，不是假装已经自动获取全A股历史数据。要做严格的全A股多因子历史回测，需要逐日股票池、财务数据发布日期、复权价格、停牌/涨跌停和交易成本等数据。
