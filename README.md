# A股量化助手 V3.2

多源容错版：自动行情、股票代码直查、量化评分、K线、买入/观望/回避、10万元模拟账户。

## 部署
将 `app.py`、`requirements.txt`、`README.md` 放在 GitHub 仓库根目录。Streamlit Cloud 入口选择 `app.py`。

## 数据源说明
V3.2 优先使用 AKShare 的东方财富接口；实时行情失败时尝试新浪；单股历史行情失败时尝试腾讯历史接口。公开数据源可能限流或临时不可用，因此程序不会再因为批量行情失败而阻断代码直查。

## 使用
推荐输入 6 位股票代码，例如 `600519`，点击“开始量化分析”。名称搜索依赖批量行情列表，若批量列表暂时不可用，请直接使用股票代码。

## 风险
本工具仅用于研究、信息整理和模拟，不构成投资建议。公开行情/财务数据可能存在延迟、缺失或接口波动。
